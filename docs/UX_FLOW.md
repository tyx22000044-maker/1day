# 1Day — 用户流程

> 版本：v3.0 · 最后更新：2026-06-29
> 目的：描述用户一步一步怎么走，让页面、按钮、状态变化更清楚。
> 权威来源：PRD.md v3.0 第十节

---

## Flow 1：快速创建任务（今日视图输入栏）

**入口**：Tab 1 今日视图，顶部快速输入栏

```
1. 用户点击输入栏 → 键盘弹出
2. 输入文字（如"买菜"）
3a. 按回车 →
    3a.1 创建 PlanItem: title="买菜", dueDate=今天, priority=.none, status=.pending
    3a.2 任务出现在今日列表中（从底部滑入动画 0.3s）
    3a.3 触觉反馈（success）
    3a.4 输入栏清空，键盘保持（方便连续输入）
    3a.5 如果是第一次设置日期 → 触发通知权限请求
3b. 长按发送按钮 →
    3b.1 弹出日期选择器 Sheet
    3b.2 选项：今天 / 明天 / 本周 / 选择日期 / 稍后安排
    3b.3 选择"稍后安排" → 创建 PlanItem: dueDate=nil（出现在 Tab 2"未安排"分组）
    3b.4 选择日期 → 创建 PlanItem: dueDate=选择的日期
4. 输入为空时按回车 → 无操作
```

## Flow 2：完整创建任务（+ 按钮）

**入口**：Tab 1 或 Tab 2 右上角 + 按钮

```
1. 点击 + 按钮 → 弹出 Sheet（从底部滑入）
2. Sheet 内容（表单）：
   - 标题（TextField，必填，占位文字"任务标题"）
   - 备注（TextEditor，可选，占位文字"添加备注…"）
   - 日期（DatePicker，可选，显示"设置日期"按钮）
   - 优先级（Picker：无 / 低 / 中 / 高）
   - 提醒时间（可选，显示"自定义提醒"按钮）
   - [V1.1] 收藏集（Picker，可选）
   - [V1.1] 标签（多选，可选）
3. 点击「保存」→
   3.1 验证标题不为空
   3.2 创建 PlanItem
   3.3 如果有 dueDate → 调度本地通知
   3.4 触觉反馈（success）
   3.5 关闭 Sheet
   3.6 如果 dueDate 是今天 → Tab 1 列表刷新
4. 点击「取消」→ 关闭 Sheet，不保存
5. 标题为空点保存 → 标题 TextField 显示红色边框 + 提示"请输入标题"
```

## Flow 3：AI 创建任务（聊天 → 确认页）

**入口**：Tab 3 AI 聊天界面

```
1. 用户在输入框输入自然语言（如"明天下午三点开会讨论 Q3 计划"）
2. 点击发送 →
   2.1 用户消息显示在右侧气泡
   2.2 AI 侧显示加载动画（三个跳动的点）
3. AI 解析 →
   3a. 本地 LocalAIIntentParser 先尝试匹配 →
       匹配成功 → 直接生成草稿（不调用 API）
   3b. 本地无法匹配 → 发送给 AI 服务商 →
       返回结构化 JSON → 解析为意图
   3c. AI 返回纯文本 → 直接显示在左侧气泡，流程结束
4. 解析成功 → AI 侧气泡显示草稿摘要 + 「确认创建」按钮
5. 用户点击「确认创建」→ 弹出确认页 Sheet：
   5.1 结构化卡片展示所有解析字段：
       - 标题：「开会讨论 Q3 计划」（可编辑）
       - 日期：「明天 15:00」（可修改）
       - 优先级：「无」（可修改）
       - 提醒：「使用默认」（可修改）
   5.2 每个字段旁边有编辑图标
6. 用户可修改任何字段
7a. 点击「确认」→
    7a.1 创建 PlanItem
    7a.2 调度本地通知
    7a.3 AI 侧气泡更新为「✅ 已创建：开会讨论 Q3 计划」
    7a.4 底部显示撤销 toast（3 秒内可撤销）
    7a.5 触觉反馈（success）
7b. 点击「取消」→ 关闭确认页，AI 侧气泡显示「已取消」
8. 撤销 toast 点击 →
   8.1 删除刚创建的 PlanItem
   8.2 取消对应通知
   8.3 AI 侧气泡更新为「↩️ 已撤销」
```

**错误处理**：
```
- API 请求超时（15s）→ AI 侧气泡显示「请求超时，请重试」+ 重试按钮
- API Key 无效 → AI 侧气泡显示「API Key 无效，请在设置中检查」+ 跳转设置按钮
- 解析失败 → AI 侧气泡显示「无法理解您的意思，请换个说法试试」
- 网络不可用 → AI 侧气泡显示「网络不可用，请检查网络连接」
```

## Flow 4：创建独立笔记

**入口**：Tab 4 笔记列表，右上角 + 按钮

```
1. 点击 + 按钮 → 进入笔记编辑页（Push 导航）
2. 编辑页内容：
   - 标题（TextField，可选，占位文字"笔记标题"）
   - 正文（TextEditor，占位文字"开始写…"）
   - [V1.1] 标签选择
3. 用户编写内容
4. 点击返回（导航栏 Back 按钮）→
   4.1 如果标题和正文都为空 → 不创建，静默丢弃
   4.2 如果有内容 → 自动保存 Note
   4.3 返回笔记列表，新笔记出现在列表顶部
5. 编辑已有笔记 → 点击列表中的笔记 → 进入编辑页 → 修改 → 返回自动保存
6. 删除笔记 → 列表中左滑 → 显示「删除」按钮 → 点击 → 二次确认 → 删除
```

## Flow 5：从事件添加笔记（V1.2）

**入口**：事件详情页底部「笔记」区域

```
1. 用户从 Tab 1 或 Tab 2 点击一个事件 → 进入事件详情页
2. 详情页底部显示「笔记」区域：
   - 已有笔记列表（标题 + 内容预览）
   - 「添加笔记」按钮
3. 点击「添加笔记」→ 进入笔记编辑页
   3.1 编辑页顶部显示关联信息：「关联：Q3 规划会议 · 10:00-12:00」
   3.2 自动设置 Note.linkedItem = 当前事件
4. 编写笔记 → 返回自动保存
5. 保存后：
   5.1 笔记出现在事件详情页的笔记列表中
   5.2 同一条笔记也出现在 Tab 4 笔记列表中（带关联事件标签）
6. 从 Tab 4 点击有关联的笔记 → 进入编辑页 → 顶部显示关联事件 → 可点击跳转到事件详情
```

## Flow 6：证件照片保存和取用（V1.3）

**入口**：Tab 5 设置 → 证件管理

```
1. 点击「证件管理」→ Face ID / Touch ID 验证
   1a. 验证成功 → 进入证件列表页
   1b. 验证失败 → 提示「认证失败，请重试」，不进入
2. 证件列表页：
   - 网格布局，每张证件显示：类型图标 + 名称 + 到期状态
   - 到期状态：绿色「有效」/ 橙色「即将到期」（30天内）/ 红色「已过期」
   - 右上角 + 按钮添加新证件

添加证件：
3. 点击 + → 进入添加证件 Sheet
4. 填写：
   - 证件名称（如"我的护照"）
   - 证件类型（Picker：身份证/护照/驾照/港澳通行证/社保卡/其他）
   - 正面照片（点击拍照或从相册选择）
   - 反面照片（可选）
   - 到期日期（可选，DatePicker）
   - 备注（可选）
5. 点击「保存」→
   5.1 照片保存到 Documents/Credentials/ 目录
   5.2 Document 模型保存到 SwiftData
   5.3 如果设置了到期日期 → 调度到期前 30 天的本地通知
   5.4 返回证件列表

使用证件（典型场景：上传身份证照片）：
6. 点击证件卡片 → 进入证件详情页
7. 查看正反面照片（支持缩放手势）
8a. 长按照片 → 弹出菜单：「保存到相册」/「分享」
8b. 点击底部「保存到相册」按钮 → 保存所有照片到 Camera Roll → toast 提示「已保存」
8c. 点击底部「分享」按钮 → 系统分享 Sheet → 可发送到微信/邮件等
9. 切换到需要上传照片的 App → 从相册选取
```

## Flow 7：任务完成 + 通知取消

```
1a. 今日视图（Tab 1）右滑任务 →
1b. 计划列表（Tab 2）右滑任务 →
1c. 通知横幅点击「标记完成」→

2. PlanItem.status = .completed
3. PlanItem.completedAt = now
4. 划过横线动画（0.3s）
5. 触觉反馈（success）
6. 任务移至「已完成」区域（灰显）
7. 如果有对应的 pending notification → UNUserNotificationCenter.removePendingNotificationRequests(withIdentifiers:)
8. Tab 1 底部进度卡片更新（今日完成数 +1）
```

**撤销完成**：
```
1. 在「已完成」区域点击任务 → 进入详情
2. 点击「标记未完成」→
   2.1 PlanItem.status = .pending
   2.2 PlanItem.completedAt = nil
   2.3 任务回到待办列表
   2.4 如果有 dueDate 且未过期 → 重新调度通知
```

## Flow 8：Onboarding 全流程

```
1. Welcome 页面
   - 标题：「欢迎使用 1Day」
   - 副标题：「安排要做的，记录在想的，复盘已完成的」
   - 三个价值点图标 + 文字
   - 底部「开始」按钮
   - 点击「开始」→ 进入 Language

2. Language 页面
   - 标题：「选择语言」
   - 选项列表：简体中文 / English
   - 选中后底部「继续」按钮高亮
   - 点击「继续」→ 保存 UserSettings.language → 进入 Profile

3. Profile 页面
   - 标题：「设置你的资料」
   - UserAvatarView（可点击选择照片）
   - 昵称 TextField
   - 底部「继续」按钮（昵称可为空，使用默认值）
   - 点击「继续」→ 保存 UserSettings.userName + avatarImageData → 进入提醒时间

4. 默认提醒时间 页面
   - 标题：「每天几点提醒你待办事项？」
   - 预设选项：8:00 / 9:00（默认高亮）/ 10:00
   - 「自定义时间」按钮 → 展开 TimePicker
   - 底部「继续」按钮
   - 点击「继续」→ 保存 UserSettings.defaultReminderTime → 进入 AI Config

5. AI Config 页面
   - 标题：「配置 AI 助手」
   - 副标题：「AI 功能是可选的，你可以随时在设置中配置」
   - 服务商选择列表
   - API Key 输入框
   - 「测试连接」按钮
   - 底部两个按钮：「跳过」/「完成配置」
   - 点击「跳过」→ 进入 Ready（不保存 AI 配置）
   - 点击「完成配置」→ 保存 Key 到 Keychain → 进入 Ready

6. Ready 页面
   - 标题：「一切就绪！」
   - 摘要卡片：显示用户设置的昵称、提醒时间、AI 状态
   - 底部「开始使用」按钮
   - 点击「开始使用」→ 标记 Onboarding 完成 → 进入主界面 Tab 1
   - 触觉反馈（success）
```

## Flow 9：数据备份与恢复

**入口**：Tab 5 设置 → 数据管理

### 备份

```
1. 点击「导出备份」
2. 生成 JSON 文件，包含：
   - 所有 PlanItem
   - 所有 Note
   - UserSettings（不含 avatarImageData）
   - [V1.1] Collection、Tag
   - [V1.3] Idea、ReviewEntry、Document 元数据（不含照片）
   - 不含：AI API Key、证件照片
3. 弹出系统分享 Sheet → 用户选择保存位置（文件 / AirDrop / 云盘等）
4. 导出成功 → toast 提示「备份已导出」
```

### 恢复

```
1. 点击「导入备份」
2. 弹出文件选择器 → 用户选择 JSON 文件
3. 解析文件 →
   3a. 解析成功 → 显示确认弹窗：
       「将导入 X 个任务、Y 条笔记。当前数据将被替换，此操作不可撤销。」
       按钮：「取消」/「导入」（红色）
   3b. 解析失败 → 提示「文件格式不正确，请选择有效的 1Day 备份文件」
4. 点击「导入」→
   4.1 清空现有数据
   4.2 写入备份数据
   4.3 触觉反馈（warning，因为是替换操作）
   4.4 toast 提示「已导入 X 个任务、Y 条笔记」
```

### 清空数据

```
1. 点击「清空所有数据」
2. 第一次确认：Alert「确定要清空所有数据吗？此操作不可撤销。」
   按钮：「取消」/「清空」（红色）
3. 点击「清空」→ 第二次确认：Alert「请再次确认：所有任务、笔记和设置将被永久删除。」
   按钮：「取消」/「确认清空」（红色）
4. 点击「确认清空」→
   4.1 删除所有 PlanItem、Note
   4.2 重置 UserSettings 为默认值
   4.3 [V1.3] 删除证件照片文件
   4.4 触觉反馈（warning）
   4.5 返回设置页
```
