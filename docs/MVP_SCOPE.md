## V1.0 开发结构约束

- View 负责展示、输入和导航，不承载跨页面复用的业务规则。
- 任务创建、完成/撤销完成、删除优先通过 `PlanItemService`。
- 通知调度和取消由 `NotificationService` 负责，不直接写在 View 中。
- JSON 导出/恢复由 `JSONBackupService` 负责，不直接写在设置页中。
- AI 只能生成草稿；确认后保存时再通过任务服务层写入 SwiftData。
- V1.2 前不为 `PlanItem` 添加事件字段（`type/startDate/endDate/location`）。
